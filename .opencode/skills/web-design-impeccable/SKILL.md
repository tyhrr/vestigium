# Web Design with Impeccable

When the user asks to modify, improve, redesign, or fix a web page (HTML/CSS/frontend), you MUST:

1. Load the `impeccable` skill first.
2. Run `impeccable context` in the project.
3. Follow impeccable methodology (audit, craft floor, polish) for all design-related changes.
4. Only then apply code edits.

This skill ensures consistent, high-quality design work across web tasks.
